# Kequiv - ระบบจัดการเอกสารธุรกิจและลูกค้า (Non-VAT)
### Business Document & Customer Management System

ระบบเว็บแอปพลิเคชันสำหรับธุรกิจขนาดเล็ก ร้านค้า และผู้รับเหมา ออกแบบมาสำหรับร้านค้าที่**ไม่ได้จดทะเบียนภาษีมูลค่าเพิ่ม (ไม่มี VAT)** มีระบบป้องกันการรันเลขที่เอกสารชนกัน 100% พร้อมระบบกันเลขล่วงหน้าสำหรับออกบิลย้อนหลัง และรองรับลูกค้า 1 รายมีได้หลายหัวบิล/หลายโครงการ

---

## 🌟 ฟีเจอร์หลัก (Core Features)

### 1. ระบบป้องกันเลขที่เอกสารชนกัน & กันเลขออกบิลย้อนหลัง (Zero Collision & Reserved Pool)
- **Zero Collision Guarantee:** ใช้ตาราง Sequence + Transaction Lock + Database Unique Constraint ป้องกันเลขซ้ำเด็ดขาด 100%
- **คลังเลขที่กันไว้ (Reserved Numbers Pool):** สามารถกด "กันเลขล่วงหน้า" ทีละเลข หรือ "กันเลขเป็นชุด" (เช่น กันไว้ 5 เลขสำหรับเดือนนี้)
- **ระบบ Auto-run ข้ามเลขที่กันไว้:** เมื่อมีการออกบิลปัจจุบันตามปกติ ระบบจะข้ามเลขที่ถูกกันไว้ในคลังโดยอัตโนมัติ ทำให้เลขไม่ชนกัน
- **การออกบิลย้อนหลัง:** สามารถเลือกดึงเลขจากคลังที่กันไว้ มาออกบิลพร้อมระบุวันที่ย้อนหลังได้อิสระ เมื่อออกเสร็จเลขจะเปลี่ยนสถานะเป็นใช้งานแล้วทันที

### 2. ลูกค้า 1 คน มีได้หลายหัวบิล / หลายโครงการ (CRM & Multiple Projects)
- จัดการข้อมูลลูกค้าหลัก (ชื่อ, ที่อยู่, เลขผู้เสียภาษี, เบอร์โทร, อีเมล)
- ภายใต้ลูกค้า 1 ราย สามารถเพิ่ม **"โครงการ / หัวบิลย่อย"** ได้ไม่จำกัด (เช่น โครงการคอนโดสุขุมวิท, โครงการปรับปรุงบ้านราชพฤกษ์)
- แต่ละโครงการระบุที่อยู่หน้างาน และผู้ประสานงานเฉพาะหน้างานได้
- ประวัติเอกสารและยอดเงินแยกจัดกลุ่มตามโครงการได้ชัดเจน

### 3. รองรับเอกสารธุรกิจ 3 ประเภท (ไม่มี VAT 7%)
1. **ใบเสนอราคา (Quotation / QT)**
2. **ใบแจ้งหนี้ / ใบวางบิล (Invoice & Billing Note / INV)**
3. **ใบเสร็จรับเงิน (Receipt / RE)**
> 💡 ทุกเอกสารจะ**ไม่มีคำว่า "ใบกำกับภาษี"** และคำนวณราคาแบบไม่มี VAT (Grand Total = Subtotal - ส่วนลด)

### 4. รายการสินค้า & การคำนวณขั้นสูง
- เพิ่ม/ลบแถวสินค้าแบบไดนามิก
- จำนวนรองรับเลขทศนิยม (เช่น `2.5` ตร.ม.)
- มีหน่วยนับสินค้าให้เลือกเป็น Preset หรือพิมพ์เองได้ (ชิ้น, งาน, เมตร, ตร.ม., ชุด, ม้วน, กล่อง, เที่ยว, lot, งวด ฯลฯ)
- รองรับส่วนลดรายแถว (บาท หรือ %) และส่วนลดท้ายบิล
- **แปลงจำนวนเงินเป็นตัวอักษรภาษาไทยอัตโนมัติ** (เช่น `หนึ่งหมื่นห้าพันบาทถ้วน`) แบบเรียลไทม์

### 5. วงจรชีวิตเอกสาร & การแปลงเอกสาร (Lifecycle & Conversion)
- แปลงใบเสนอราคา (QT) ➜ ใบแจ้งหนี้/วางบิล (INV) ➜ ใบเสร็จรับเงิน (RE) ได้ด้วย 1 คลิก
- คัดลอกเอกสาร (Duplicate) เพื่อออกฉบับใหม่รวดเร็ว
- ยกเลิกเอกสาร (Void) โดยไม่ลบออกจากฐานข้อมูล มีประทับตรา "ยกเลิก" และเก็บเหตุผลไว้เป็นหลักฐาน

### 6. เลย์เอาต์พิมพ์ขนาดมาตรฐาน A4 (Print & PDF)
- หน้าตาเอกสารมืออาชีพ เรียบหรู จัดสัดส่วนพอดีกระดาษ A4
- แสดงข้อมูลร้านค้า, โลโก้, ข้อมูลบัญชีธนาคารสำหรับโอนเงิน
- ช่องลงลายมือชื่อผู้สั่งซื้อ/ผู้รับบริการ และผู้มีอำนาจลงนาม/ผู้รับเงิน

### 7. ตั้งค่าข้อมูลร้านค้า (Company Profile)
- แก้ไขชื่อร้านค้า, ที่อยู่, เบอร์โทร, Line ID, เลขผู้เสียภาษี, โลโก้
- จัดการข้อมูลบัญชีธนาคารสำหรับรับเงินได้หลายธนาคาร
- เลือกรูปแบบปีในเลขรันเอกสาร: **พ.ศ. (2569)** หรือ **ค.ศ. (2026)**
- ตั้งค่าเงื่อนไขการชำระเงินและหมายเหตุเริ่มต้น

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. ลงข้อมูลตัวอย่าง (Seed Data)
```bash
npm run seed
```

### 3. เริ่มต้นใช้งานระบบ (Start Server)
```bash
npm start
```
เปิดเบราว์เซอร์แล้วเข้าใช้งานได้ทันทีที่:
👉 **http://localhost:3000**
